# Codex Instructions

This repository stores gluten-free family recipes.

## Core rules

- All recipes must be gluten-free or clearly marked as requiring gluten-free substitutions.
- Include celiac-safety notes for every recipe.
- Prefer low-carb notes or adjustment options where useful.
- Do not invent ingredients, measurements, cooking times, temperatures, or steps.
- If details are missing, add a `Needs clarification` note instead of guessing.
- Use Markdown only.
- Use one recipe per file.
- Use kebab-case filenames.

## Folder rules

Place recipes under:

```text
recipes/breakfast/
recipes/dinner/
recipes/snacks/
recipes/desserts/
```

Create new folders only when a recipe clearly does not fit these categories.

## Recipe format

Use the structure from `templates/recipe-template.md`.

## Commit guidance

Use concise commit messages, for example:

```text
Add low-carb chicken parmesan recipe
Add gluten-free snack template
Update recipe index
```
